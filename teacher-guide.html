시작하는 방법

관리자에게 학교 등록 요청

아래 정보를 알려주세요. 등록이 완료되면 바로 사용 가능합니다.

  • 학교명: 예) 서울중앙고등학교
  • 선생님 성함: 예) 홍길동 선생님
  • 사용할 학년: 예) 1, 2학년
  • 학급 수: 예) 각 학년 10반
  • 관리용 이메일: 예) teacher@gmail.com

관리자 계정 생성

등록이 완료되면 관리자 로그인용 이메일과 비밀번호를 안내받습니다. 이 계정으로 대시보드에 로그인하면 우리 학교 데이터만 볼 수 있습니다.

학생에게 URL 안내

학교 전용 URL을 학생에게 공유하면 끝! 학생은 별도 로그인 없이 바로 진단을 시작합니다.

https://ai-literacy-test-greatsong.vercel.app/?school=학교코드

결과 확인

학생이 진단을 마치면, 대시보드에서 실시간으로 결과를 확인할 수 있습니다. 학급별 평균, 영역별 분석, CSV 다운로드 모두 지원됩니다.

자주 묻는 질문

비용이 있나요?

무료입니다. 별도의 설치나 서버 비용이 없습니다.

다른 학교 데이터가 보이나요?

아니요. 각 학교 선생님은 자기 학교 데이터만 볼 수 있습니다. 데이터는 학교별로 완전히 분리되어 있습니다.

학생이 로그인해야 하나요?

아니요. 학생은 이름, 학년, 반만 입력하면 바로 시작할 수 있습니다. 별도 회원가입이 필요 없습니다.

진단 시간은 얼마나 걸리나요?

20문항으로 약 10~15분 정도 소요됩니다. 시나리오를 읽고 가장 적절한 행동을 선택하는 방식입니다.

스마트폰에서도 되나요?

네, 모바일/태블릿/PC 모두 지원됩니다. 별도 앱 설치 없이 웹 브라우저에서 바로 사용할 수 있습니다.

선택과목 반도 설정할 수 있나요?

네, 특정 학년에 선택과목 반(예: AI기초, 정보과학 등)을 별도로 설정할 수 있습니다. 등록 시 말씀해주세요.
